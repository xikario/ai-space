# 文档提取与旧版演示

正文提取入口为 `apps/ai-space/scripts/smart_space_extract.py`，旧版演示解析器为同目录的 `legacy_ppt.py`。

PowerPoint 97–2003 `.ppt` 及采用相同结构的 WPS `.dps` 可直接提取当前幻灯片的页面文字和页码，无需启动办公软件。解析器依据 MS-PPT 的当前编辑链和页面引用读取文本，不把已删除的旧页面、母版或任意二进制字符串当作正文。

图片文字、备注和嵌入对象不在旧版演示解析范围内；结果明确标为部分提取。加密、损坏或没有可提取正文的文件会给出原因，失败时保留此前已入库的正文。已有失败项可在「当前状态详情 → 处理失败 / 已忽略」中选择后重新处理。

可复现检查：

```sh
python3 -m unittest discover -s apps/ai-space/tests -p test_legacy_ppt.py -v
```

测试使用代码生成的 OLE 夹具，覆盖当前页面顺序、旧编辑排除、中文文本、加密与损坏输入。它不替代所有办公软件版本的内容准确性验收。

纯文本先检查 BOM、NUL / 控制字节和 MPEG-TS 同步字节，避免把视频或改后缀的二进制当成正文。无 BOM 文本先试 UTF-8，再试 GB18030；后续坏字节替换并标记为部分提取。RTF 只保留可见文本。XML 拒绝 DTD / 实体声明，并限制单个 XML 成员读取量。

每文档正文默认最多 8 Mi 字符；达到上限会显示“部分入库”。高级命令行环境变量 `AI_SPACE_MAX_DOCUMENT_CHARS` 可设置 1024–67108864 字符。该预算独立于预览预算和整库数据库配额，不保证所有大型文档均能完整提取。

WPS 按文件实际内部结构识别：支持与 OOXML、OLE Office、ODF 相兼容的容器，不承诺全部 WPS 原生私有格式。无法识别的文件给出明确失败原因，不从任意二进制字符串恢复正文。真实 OEM / WPS 版本仍需使用可公开的样本验收。

OCR 默认 `chi_sim+eng`，可在向导使用 `chi_tra`、`jpn` 等 Tesseract 语言代码，用 `+` 连接；须先安装对应语言包。语言选择不等同于查询分词覆盖，当前检索分词的语言边界仍见 README。缓存键包含语言选择，缺包在任务开始前提示，不把缺包误报为文件损坏。
