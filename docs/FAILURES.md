# 知识库失败项：重试、忽略与恢复

## 使用

点击主窗口左下角状态 →「处理失败 / 已忽略…」。

- 列表显示失败和来源缺失的文件，每页 50 项，支持多选和全选本页。选中后可查看完整路径、失败原因和最近尝试时间。
- 顶部原因分类显示每类数量，可筛选“文件加密”“格式不支持”“文件损坏 / 结构异常”“文本提取失败”“OCR / 页面转换失败”等；没有记录的分类自动收起，当前选中的空分类仍保留。
- 例如处理加密文件：选择「文件加密」→「全选筛选结果」→「忽略选中（数量）」。全选覆盖该分类所有页；翻页后保持跨页选择，切换分类或列表状态会取消选择。按钮和选择计数明确显示处理范围。
- 「全选本页」及表格中的 Ctrl+A 只选当前页；「取消跨页全选」清除跨页选择。可在“已忽略”中按同样分类全选并恢复。
- 「重新处理选中」重新检查并提取这些文件。默认勾选“需要时补 OCR”，可取消；使用当前单核 CPU、工作进程内存、磁盘保留空间及单库上限。
- 「忽略选中」记录忽略偏好，普通增量、文本和 OCR 阶段都会跳过这些文件。已有正文和真实提取状态保留，不把失败改成成功，也不隐藏已存正文的检索结果。
- 切换到「已忽略」，可多选「取消忽略」；取消本身不会启动任务。也可直接重新处理，开始处理该文件时取消其忽略。
- 共享 AIKB 文件只读，列表可查看；需要在资料来源机器处理后重新导出新版本。

来源文件仍缺失、损坏或格式不支持时，重试会更新失败原因，保留已存正文。重试结束只代表本轮任务结束，界面会给出仍失败/缺失的数量；部分提取、无正文继续按真实质量统计。

## 失败原因中文说明

失败列表、所选文件详情和状态弹窗中的失败示例统一使用中文说明，并给出可采取的处理办法。例如旧版 PPT 建议使用当前版本重新处理，加密工作簿建议解密后重新处理；PDF 提取、文字识别、文件损坏、编码、权限、超时和缺少工具分别解释。OCR 待处理页、空白识别页和部分提取的原因也提供中文描述。

转换在读取时完成，历史记录重新打开即可看到中文，无需重新建库。数据库中的原始问题标记和 `issues` 接口字段保留，供 OCR 队列判断和故障排查；接口补充中文 `reason`、`issueDescriptions` 与原始 `technical_reason`。未识别的新错误使用中文提示，并保留原始诊断，不猜测具体原因。


## 数据及资源边界

个人库的可选 `ignored_documents` 表保存文档 ID 和忽略时间，和 `extraction_state` 分开。忽略和恢复使用与建库相同的文件锁及 SQLite 事务，建库运行时拒绝修改，不删除文档、正文或 FTS 行。

重试通过 `knowledge_jobs.py --retry-documents-json` 管理，精确传递详情页选中的数据库路径，支持自定义文件名，拒绝写共享 AIKB。输入为已有失败或忽略文档 ID，不执行 Provider，也不重新遍历其他资料目录。所选文件的元数据在提取时重新读取。

每个完成的文档提交一次，支持暂停。重试不替换全量扫描清单，不清理其他文档，不修改其他目录的可用性，不全表统计百万正文片段。已有未对齐的老 FTS 索引仍可能需要一次兼容迁移；重试不会以未对齐索引执行不安全的更新。

单次重新处理及显式 ID 操作最多 200 个文档；界面每页最多选择 50 个。跨页全选可以一次忽略或恢复超过 200 项，使用单个事务处理全部匹配文件；不通过逐批提交绕过上限，不改变重试任务的资源边界。超过 200 项时重新处理按钮禁用，可改为按页选择。

跨页全选记录当前分类、待处理/已忽略状态、文件 ID 与诊断修订的摘要。保存时在建库写锁和 SQLite 写事务内重新验证；新增匹配文件、原记录变化或范围不一致时拒绝整次操作，提示刷新，不把新出现的记录悄悄纳入选择。关闭或失败时未提交的事务回滚。分类基于已存诊断，在后台只读扫描失败元数据，不访问源文件或全文索引，不新增空闲轮询。

全部操作均为用户明确触发，安装后不会自动忽略或重新处理正式库中的失败文件。
